## 🎨 **CPHL Patterns**

### **Component Creation**
```
@context[domain=web, framework=React]
@intent[Create functional component]
@constraints[
  - TypeScript types
  - Accessibility
  - Error handling
]
@examples[
  const Component = () => <div>Hello</div>
]
```

### **API Design**
```
@context[domain=backend, type=REST]
@intent[Design user management API]
@constraints[
  - RESTful principles
  - Authentication
  - Rate limiting
]
@patterns[
  GET /users - list users
  POST /users - create user
]
```

### **Database Schema**
```
@context[domain=database, type=PostgreSQL]
@intent[Design e-commerce schema]
@constraints[
  - Normalized design
  - Performance optimized
  - ACID compliance
]
```
