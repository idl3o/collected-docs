# Getting Started with Real Internet Data

## Step 1: Get API Keys (5 minutes)

### NewsAPI (Free)
1. Go to https://newsapi.org/
2. Sign up for free account
3. Get your API key
4. Add to `.env`: `REACT_APP_NEWS_API_KEY=your_key_here`

### OpenWeatherMap (Free)
1. Go to https://openweathermap.org/api
2. Sign up for free account  
3. Get your API key
4. Add to `.env`: `REACT_APP_WEATHER_API_KEY=your_key_here`

## Step 2: Enable Internet Learning

```bash
# Copy environment template
cp .env.example .env

# Edit .env with your API keys
# Set REACT_APP_ENABLE_INTERNET_LEARNING=true
```

## Step 3: Test Integration
