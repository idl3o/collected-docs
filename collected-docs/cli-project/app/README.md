## 🛠️ Development Setup

### **Quick Start**
```powershell
# Clone and setup
git clone <repository-url>
cd consciousness-platform
npm install

# Development server (with hot reload)
npm run dev
# ➜ Local: http://localhost:5178/

# Production build and preview
npm run build
npm run preview  
# ➜ Local: http://localhost:4173/

# PWA-specific build
npm run build:pwa
```
