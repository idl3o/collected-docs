## 🌟 GETTING STARTED

### **Quick Start Commands**

```bash
# Clone and setup
git clone [repository-url]
cd consciousness-platform

# Install dependencies  
npm install

# Start PWA development
cd app && npm run dev

# Start CLI development
consciousness --help

# Run both interfaces

```

### **Development Environment**

- **Node.js** 18+ required
- **TypeScript** 5.8+ for consciousness system development
- **Modern Browser** Chrome 88+, Firefox 86+, Safari 14+
- **Terminal** PowerShell, Bash, or Zsh for CLI usage
