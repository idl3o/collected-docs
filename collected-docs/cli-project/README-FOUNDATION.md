## 🚀 Quick Start

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Installation
```bash
git clone <repository-url>
cd consciousness-platform
cd app
npm install
```

### Development
```bash
npm run dev
```
Open http://localhost:5173 in your browser.

### Build
```bash
npm run build
```
