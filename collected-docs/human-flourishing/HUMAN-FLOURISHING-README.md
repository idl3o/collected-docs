# 🌍 Planetary Wisdom Time Capsule

> *A collaborative effort to preserve and share the knowledge needed for human flourishing*

## Overview

The Planetary Wisdom Time Capsule is a digital repository designed to address "the great planetary civilisation filter" - the critical challenge of navigating present and impending global catastrophes while maximizing human flourishing. This project synthesizes ancient wisdom, modern research, and practical solutions to guide humanity toward a thriving future.

## Vision

Instead of population collapse, we envision a path toward utopia for our entire planetary complex. By combining:
- **Timeless wisdom** from global traditions
- **Evidence-based solutions** from modern research  
- **Practical action frameworks** for individuals and communities
- **Systems thinking** that honors interconnectedness

We can create a comprehensive guide for civilizational transformation.

## Getting Started

### Prerequisites
- Node.js (v16 or higher)
- Git

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/human-flourishing.git
cd human-flourishing

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

### Development

The project is structured for easy content updates and expansion:

```
src/
├── app.js              # Main application controller
├── style.css           # Global styles
├── main.js             # Entry point
└── modules/
    ├── inequality.js   # Civilizational inequalities content
    ├── solutions.js    # Solution pathways content
    ├── wisdom.js       # Ancient wisdom content
    └── action.js       # Action frameworks content
```
