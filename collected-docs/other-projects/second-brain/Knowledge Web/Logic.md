# Logic

**Summary:**
Logic is the systematic study of reasoning and inference, which aims to establish universally applicable principles for drawing conclusions from given premises.

**Key Frameworks:**
- Classical Logic
- Modal Logic
- Intuitionistic Logic
- Fuzzy Logic
- Substructural Logic
