# Proof Theory

**Summary:**
Proof theory is a branch of mathematical logic that deals with the study of the fundamental nature of mathematical proofs and their formalization. It provides a framework for analyzing and constructing proofs, focusing on the deductive structure of mathematics.

**Key Frameworks:**
- Propositional Logic
- First-Order Logic
- Type Theory
