# Abstraction

**Summary:**
Abstraction enables humans to recognize and understand complex relationships between concepts, enabling the effective simplification of complex information into actionable knowledge. This process allows for more efficient decision-making, improved communication, and increased problem-solving capabilities.

**Key Frameworks:**
- Parnas' Software Abstraction Framework
- Abductive Reasoning Framework
- Ternary Logic
