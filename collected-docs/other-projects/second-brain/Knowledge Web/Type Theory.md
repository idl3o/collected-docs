# Type theory

**Summary:**
Type theory is a branch of mathematics that deals with the study of types, which are sets of values that have common properties or characteristics. It provides a framework for defining and manipulating types in the context of programming languages, allowing for more precise and efficient code.

**Key Frameworks:**
- Homotopy Type Theory
- Dependent Types
- Higher-Order Logic

**Actionable Insights:**
- Cohesion and separation are crucial concepts in type theory; types must be cohesive to ensure compatibility and separated to maintain modularity
- The Curry-Howard correspondence is a fundamental principle linking type theory to proof theory, where propositions are identified with types
- Type inference can significantly improve the development of programming languages by eliminating explicit type annotations
