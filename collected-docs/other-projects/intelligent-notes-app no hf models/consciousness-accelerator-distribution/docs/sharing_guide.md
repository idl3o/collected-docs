## How to Share

### 1. Direct Installation Sharing

**Send the installer:**
```bash
# Share this exact command
python installers/cli_installer_windows.py
```

**Or share the one-liner:**
```bash
# For quick/minimal sharing
python installers/one_line_installer.py
```

### 2. Folder Distribution

**Copy the entire package:**
1. Copy `consciousness-accelerator-distribution/` folder
2. Share via USB drive, cloud storage, or file transfer
3. Recipients run any installer from `installers/` folder

### 3. QR Code Sharing

Create QR codes linking to:
- GitHub repository
- Download links
- Installation instructions

Perfect for:
- Workshop handouts
- Conference materials
- Physical distribution

### 4. Social Media Sharing
