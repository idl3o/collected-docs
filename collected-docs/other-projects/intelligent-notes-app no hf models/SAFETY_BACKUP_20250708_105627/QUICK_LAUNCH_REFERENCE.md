## 🔧 Troubleshooting

### **Port Conflicts**
- **Automatic**: The new PortManager resolves conflicts automatically
- **Manual**: Use `netstat -ano | findstr :5000` to check port usage

### **Dependencies**
```bash
# Install/update requirements
pip install -r requirements.txt
```

### **Platform Not Starting**
1. Run `python start_platform.py` for detailed diagnostics
2. Check `python check_platform_status.py` for health status
3. Verify Ollama is running: `ollama list`
