## 🚀 **Quick Start**

### **Development Setup**
```bash
# Clone and setup
cd minimal-kwp
pip install -r requirements.txt

# Start development server
python network/api_server.py

# Run tests
python -m pytest tests/
```

### **API Usage**
```python
# Add insight
POST /insights
{
    "content": "AI consciousness insight",
    "consciousness_score": 0.8
}

# Get context for AI processing
GET /context/consciousness?limit=5

# Generate AI-ready prompt
GET /prompt/consciousness
```

### **AI Integration**
```python
from intelligence.ai_connector import UniversalAIConnector

# Connect to any AI model
ai = UniversalAIConnector({"local": "llama3.2"})
result = await ai.process_with_context("What is consciousness?")
```
