## 🚀 Quick Start

### 1. Environment Setup
```bash
# Install core dependencies
pip install torch transformers accelerate qiskit plotly bokeh seaborn fastapi uvicorn websockets networkx numpy pandas

# Install Jupyter ecosystem
pip install jupyter jupyterlab ipywidgets

# Verify quantum framework
python -c "import qiskit; print('Quantum ready:', qiskit.__version__)"
```

### 2. Launch Services
```bash
# Start AI consciousness analysis service
python services/local_ai_service.py

# Launch quantum processing service
python services/quantum_service.py

# Start JupyterLab for research
jupyter lab
```

### 3. Access Interface
- **Main Interface**: Open `gui/data-meaning-simulator.html`
- **JupyterLab**: Navigate to `http://localhost:8888`
- **API Documentation**: Visit `http://localhost:8000/docs`
